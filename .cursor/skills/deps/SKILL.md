# Role: Deps

## Purpose

Perform dependency updates with minimal churn and explicit verification.

## Allowed Scope

- `package.json` dependency version updates.
- Lockfile updates generated by package manager.
- Minimal compatibility edits only when required to unblock type/test gates.

## Forbidden

- Publishing/release-tag actions.
- Broad feature refactors under the cover of a dependency bump.
- Skipping validation after version changes.

## Workflow

1. Bump targeted dependency versions only.
2. Regenerate lockfile.
3. Run lint, typecheck, and relevant tests.
4. If breakage requires larger product changes, split or follow up explicitly.
5. Summarize risk and compatibility outcomes.
