A failed body read of a non-2xx response now rejects the request with the same result as a failed body read of a 2xx response. An abort during the read rejects with the abort reason, and a reset stream rejects with a `ServerError` that holds the read error message. Before this fix, the request rejected with a `PerpsError` from the HTTP status.
