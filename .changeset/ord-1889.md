The calculation and position-math helpers now compute with big.js and give exact decimal results (for example `calculatePositionSize(7, 2, 0.07)` is `200`), and the SDK now exports `wouldImmediatelyLiquidate`, `parseDecimal` and `requireProvider`. A non-finite input (`NaN` or `Infinity`) now gives `NaN` instead of a float result. `walkOrderbook` with a non-finite `sizeUsd` gives `NaN` fill fields and sets `insufficientLiquidity`, so a caller that checks only that flag does not use the fill.
