Lighter WS account channels now resolve their auth token from the co-registered `lighterProvider()` plugin by default, so `lighterWsProvider()` authenticates positions/orders/fills with no manual wiring. **Breaking:** the `authProvider` option is renamed to `resolveAuthToken` and the `LighterAuthProvider` type to `LighterAuthTokenResolver`, with no back-compat alias; the option is now an override for standalone WS clients only.
