Scope `LighterKeyStore` persisted API-key storage by the resolved provider instance key so two Lighter instances sharing one adapter (e.g. `lighter` and `lighter-rh`) no longer clobber each other's key. The default `lighter` instance keeps its existing un-namespaced storage key, so current users are not orphaned; `LighterProvider` injects its resolved `providerKey` into the supplied keystore.
