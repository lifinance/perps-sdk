First stable release of the Hyperliquid provider plugin for the LI.FI Perps SDK. Register it on `PerpsClient` via the `PerpsProvider` plugin SPI to route Hyperliquid calls.

- Agent-keypair signing with client-side key storage, typed account configuration, spot support, and ledger/activity enrichment.
