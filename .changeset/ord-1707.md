`LtAccountAsset` now aliases the generated `AccountAsset` model in `zklighter-perps`. The alias uses `import type` only, so the build output holds no reference to the package.

`margin_mode` becomes a required member. It was optional because the package TSDoc recorded that Lighter delivers it through `additional_properties`. Twenty live `/api/v1/account` bodies carry `margin_mode` as a top-level member on all 37 asset rows, so the generated model is correct and the optional member was not. The value stays the `'enabled' | 'disabled'` union. A consumer that builds an `LtAccountAsset` in a test fixture must add `margin_mode`.

`getAccount` no longer drops an asset row that omits `margin_mode` from the `assetCollateral` projection. Every held asset row now reaches the projection, and a row with no readable `margin_mode` reports `enabled: false`.
