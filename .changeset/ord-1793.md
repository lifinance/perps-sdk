The last Lighter `getPortfolioHistory` point now equals `getAccountSummary` `portfolioValue`, so spot-route balances count in the history anchor. Each `getPortfolioHistory` call now reads the account through `getAccount`, which adds the LI.FI markets context read and, when the SDK holds a registered API key, the Lighter `/api/v1/apikeys` and `/api/v1/accountLimits` reads; a failure of any of these reads rejects the history call.
