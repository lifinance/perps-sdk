`PerpsProviderPlugin` has an optional `reduceOnlyOrders` member. `rejectsOversize` tells if the venue rejects a reduce-only order larger than the position, and `limitIsImmediateOrCancel` tells if the venue runs a reduce-only limit order as Immediate or Cancel. Ondo sets both values to `true`. Hyperliquid and Lighter set both values to `false`.
