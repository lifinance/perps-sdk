End the Ondo SIWE login at the client. The SIWE arm of `ondoSignActions` now persists the session JWT and returns no signed step, so the user's wallet signature over the ERC-4361 authentication message is never posted to the LI.FI backend and `SIWE_LOGIN` skips the `/executeAction` hop entirely — the same shape Lighter's client-executed `SET_REFERRAL` already had. Login behaviour is unchanged: the JWT is stored locally, `getAccount` reports `loggedIn: true`, and the `SIWE_LOGIN` setup descriptor reads satisfied.

Breaking: `completeSiweLogin` resolves the `OndoAuthToken` directly instead of `{ token, signature }`. Callers that destructured `token` must use the returned token itself; the signature has no consumer outside the login exchange.
