Remove the reference-data registry's lookup-miss refetch. A registry miss now warns once and returns `undefined`; the index is reconciled solely by `sync()` through the HTTP layer, which every REST call and each WS (re)connect already performs. The backend owns reference-data freshness (Valkey-cached, kept warm), so the client-side cache-bypassing refetch — and the cooldown and load-generation guards it required — added no freshness and are gone.
