`getMarketSettings` reads the Lighter default leverage from the backend market `defaultLeverage` and no longer calls `/api/v1/orderBookDetails`. This replaces the initial margin fraction fallback. The backend market list must carry a positive `defaultLeverage` for every Lighter perps market; otherwise `getMarketSettings` throws a `PerpsError` with code `SDKError`.
