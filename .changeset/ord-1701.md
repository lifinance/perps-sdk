The Lighter order mappers now compare Lighter's wire spellings directly against the adopted order enums. `mapOrderType`, `mapTimeInForce` and `mapOrderStatus` no longer normalize hyphens to underscores. The `canceled-*` reasons `mapStatusReason` returns are now checked against `LtOrderStatusEnum`, so a missing literal fails to compile. `mapStatusReason` keeps its `string` parameter and still returns `undefined` for a status it does not know.
