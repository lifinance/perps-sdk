`calculateRefuelAmount` now sizes the refuel from the native gas deficit. `RefuelAmountInput` replaces `gasUsd` with `recommendedAmount` and `recommendedUsd` (the LI.FI gas suggestion), and adds `nativeBalance` (the wallet's native balance in base units). The result covers the recommendation minus the held balance, plus the new exported `REFUEL_FEE_MARGIN_PERCENT` (20%) for route fees, and is `undefined` when the wallet already holds the recommendation. `getGasRecommendation` no longer sends the `x-lifi-perps-sdk` header, which the LI.FI API CORS preflight rejects, so a browser call no longer fails with "Failed to fetch". Requests to the perps backend still send the header.
