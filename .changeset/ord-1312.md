Verify the stored Lighter API key still occupies its venue API-key slot before the first `WASM_BLOB` signature. A slot re-registered on another device now fails with the same error code as a missing registration, so the `REGISTER_API_KEY` gate renders instead of a venue rejection. A failed or inconclusive check never blocks the signature, a `REGISTER_API_KEY` batch skips the check, and a 30s freshness window keeps a burst of batches at one extra request.
