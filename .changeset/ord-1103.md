Fix `src/version.ts` reporting a stale, hand-committed version (three majors behind `package.json`) instead of the package's real version. The generator (`scripts/version.js`) now also preserves the `name`/`version` `@public` doc comments it previously stripped, and `changeset:version` regenerates the file in lockstep with every version bump so the committed source, the shipped `src/**/*.ts` files, and the built `dist` output never drift again. The `x-lifi-perps-sdk` request header and any source-consumed build now report the correct SDK version.
