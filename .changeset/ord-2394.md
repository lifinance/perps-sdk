`MarketFundingAverages.rate` is a `Partial<Record<FundingWindow, DecimalString>>`. A window with no settled rate has no key, and the rate is not `null` or zero. A measured zero rate stays a decimal string, for example `'0'`. Code that reads a window rate must handle `undefined`. `getFundingAverages` returns the backend rates and the absent windows unchanged.
