Remove the dead `asset_index` and `route_type` fields from `LtWithdrawWasmParams`. `LighterSigner.dispatch`'s `WITHDRAWAL` arm never read them — it always signs against the instance's configured collateral asset and the perps route — so any backend-declared value was silently dropped. The SDK now fully owns both values; `LtWithdrawWasmParams` only declares `amount`.
