`Position` has four optional fields: `positionValue`, `returnOnEquity`, `effectiveLeverage` and `liquidationDistance`. Each provider sets them on the REST reads and on the `positions` stream. `@lifi/perps-sdk` exports `buildPosition` and `remarkPosition`, which calculates these fields again for a live mark price.
